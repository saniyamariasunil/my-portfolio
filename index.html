Built with

A light you never have to touch. An ultrasonic sensor notices when someone is in the room and switches the LED on, and off again when the readings stop changing. A gesture sensor dims the light when I wave down and brings it back when I wave up. An Arduino Uno reads both sensors every half second and sends the data over serial to a Raspberry Pi, which stores it in MariaDB and shows it on a Flask dashboard in real time.

Shared switchesEveryone touches them, so bacteria spread in classrooms and offices.
Wear and tearConstant use wears switches out over time.

A wiring problem

The gesture sensor kept failing over I2C until I realised the wires were faulty. After I changed them, it worked normally.

What I learned

A Flask server has to be handled carefully while the database is being updated. Getting reliable serial communication between the Arduino and Raspberry Pi was my biggest win.

What I would add next

A short delay before the light switches off, so it does not flicker if I step away for a moment, and a buzzer that sounds when nobody is detected.
